# Task 3: SQL for Data Analysis

## Objective
Use SQL queries to analyze data from an e-commerce database.

## Files
- `task3_queries.sql`: SQL queries used for the task.
- `task3_outputs.txt`: Output of the SQL queries.
- `screenshots/`: Screenshots of query results.

## SQL Concepts Used
- SELECT, WHERE, ORDER BY, GROUP BY
- JOINS (INNER, LEFT, RIGHT)
- Aggregate Functions (SUM, AVG)
- Subqueries and Views
